    01

    Primitives: NAND + LATCH

    TapeOut describes NAND as the basic logic element and LATCH as the state cell. Together they are the public starting point for circuits and processors.

    Read official source ↗
    02

    Canvas → Tape Out

    Canvas experiments run in the browser. The official site describes a Tape Out as the on-chain step where transistors are burned and a Circuit NFT is created.

    Read official source ↗
    03

    Processor creation rules

    Supply, mint price and the stated revenue split are set at creation. The official site also discloses that protocol contracts remain upgradeable before a formal freeze.

    Read official source ↗
    04

    PoD: signed actions, public rules

    The official PoD page separates read-only wallet connection from irreversible signed actions. It also warns that shallow liquidity can create large price moves and mining does not require buying BEM.
